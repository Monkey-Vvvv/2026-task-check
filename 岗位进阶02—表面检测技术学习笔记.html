01

先定义“什么算缺陷”

检测之前，需要先把哪些业务规则说清楚？

表面检测的目标不是把所有与背景不同的地方都框出来，而是按质量标准识别需要处理的异常。划伤、裂纹、凹坑、污渍和氧化等外观可能相近，业务处置却不同；正常纹理、反光和接缝也可能被误判。

我把问题分为四层：有没有缺陷、属于哪类、位置和范围在哪里、是否达到报警或剔除条件。分类、目标检测、分割与异常检测分别适合不同输出，不能用一个笼统的“识别准确率”概括全部能力。

任务输出适合的需求
分类整图或区域的类别判定样本是否异常、属于哪类
目标检测框、类别、置信度找缺陷大致位置与数量
分割像素级区域测面积、轮廓和细长裂纹范围
异常检测偏离正常模式的评分或区域缺陷样本少，需要先发现异常

学习时应先写一份缺陷定义表：名称、外观特征、最小可接受尺寸、易混淆情况、标注方式和处置规则。本篇是通用技术学习笔记，流程和阈值示例不代表已经完成现场精度验证。

02

先把图像拍稳定

算法调不好，是否可能是成像条件没有固定？

工业表面常有强反光、重复纹理和局部遮挡。光照角度一变，正常区域就可能看起来像缺陷。学习算法之前，应固定相机安装、镜头、工作距离、曝光、增益和光源方案，再确认目标缺陷在图像上是否可见。

  • 明场与暗场：通过光照与观察角度改变缺陷对比；具体方案需以实际材质和缺陷验证。
  • 漫射与偏振：可用于改善反光，但不同表面、角度与光源组合的效果不同。
  • 曝光与运动：曝光太长可能造成拖影；过短又会使信号不足，应与照明和触发协同。
  • 面阵与线阵：按视野、连续运动和分辨率需求选择，线阵还需关注行频与运动同步。

如果视野宽度为 200 mm、图像宽度为 2000 px，理想平均尺度约为 0.1 mm/px；0.3 mm 缺陷只有约 3 px 宽，边缘模糊或噪声就可能明显影响识别。这个教学换算不等于测量精度承诺，实际还受镜头畸变、空间位置和标定影响。

应保留正常样本、明显缺陷、临界缺陷和难样本，观察不同位置、速度和光照下是否都能形成稳定对比。看不清的细节，不应完全寄希望于后续模型“猜出来”。

03

传统图像处理的基本链路

在使用模型之前，如何建立可解释的基线？

传统方法适合成像稳定、缺陷与背景差异明确的场景。常见流程是确定 ROI、灰度或颜色变换、去噪、背景校正、阈值分割、形态学处理、连通域筛选和几何统计。每一步都应该能解释它要消除什么干扰。

全局阈值使用同一分界；Otsu 根据灰度分布选择阈值，但并不保证对所有图像有效；自适应阈值按局部邻域计算。开运算先腐蚀后膨胀，有助于去除小的亮前景；闭运算先膨胀后腐蚀，可连接局部间隙和填小孔。核大小直接影响细小缺陷是否被保留。

Python / OpenCV 4.x

# 学习示例：生成一张带暗斑的灰度图，无需外部图片。
# 依赖：opencv-python、numpy；阈值仅用于合成图演示。
import cv2 as cv
import numpy as np

image = np.full((180, 320), 180, dtype=np.uint8)
cv.rectangle(image, (80, 60), (115, 90), 40, -1)
blurred = cv.GaussianBlur(image, (3, 3), 0)
_, mask = cv.threshold(blurred, 0, 255,
                       cv.THRESH_BINARY_INV + cv.THRESH_OTSU)
kernel = cv.getStructuringElement(cv.MORPH_RECT, (3, 3))
mask = cv.morphologyEx(mask, cv.MORPH_OPEN, kernel)
count, labels, stats, centers = cv.connectedComponentsWithStats(mask)
for index in range(1, count): # 0 是背景
    x, y, width, height, area = stats[index]
    if area >= 20:
        print({'box': (int(x), int(y), int(width), int(height)),
               'area_px': int(area)})
# 预期：打印主要暗斑的区域；没有把输出面积解释为真实 mm²。

这段示例验证流程本身，不构成现场检测器。面对划伤等细长目标，简单开运算可能把有意义的前景消掉；面对复杂纹理，阈值分割也可能把正常纹理当成异常。参数必须用目标样本和业务尺度选择。

04

模型方法与数据准备

什么时候需要深度学习，样本又该怎样组织？

当缺陷变化大、背景复杂或规则难以稳定描述时，可考虑检测、分割或异常检测模型。选型应围绕输出和业务约束，而不是只按模型名称。普通框检测适合定位与计数，细裂纹和面积统计往往需要更细的轮廓表达。

小缺陷在整图缩小后可能消失，可以考虑高分辨率输入或切片；同时要处理切片边界、重叠区域和跨片合并。切片会增加推理次数，也可能损失全局上下文，所以需要把漏检改善与时延开销一起评价。

  1. 统一标注：明确难以判断、遮挡、边界和多缺陷重叠时的规则。
  2. 覆盖变化：包含批次、材质、相机位置、正常纹理和困难负样本。
  3. 按来源划分：相邻视频帧或同一工件的近似切片应避免跨训练、测试集合泄漏。
  4. 保存版本：记录样本来源、标签版本、训练参数、模型与评估集合。

增强方法需要符合实际成像规律：任意改变颜色或几何关系可能制造现场不会出现的样本。模型错例应回到原图和成像条件分析，不能只靠继续加轮数训练解决。

05

漏检、误报与评价口径

为什么一个很高的准确率仍可能没有业务价值？

缺陷通常是低频事件。如果一千件里只有十件有缺陷，系统全部判为正常，也有 99% 的件级准确率，却漏掉了全部缺陷。因此要按实际处置需求区分漏检与误报，再明确分母和统计单位。

指标含义注意事项
Precision = TP / (TP + FP)报出缺陷的结果中有多少正确误报多会降低；分母为零时需说明处理方式
Recall = TP / (TP + FN)真实缺陷中有多少被找出关注漏检；需定义匹配规则
漏检率 = FN / (TP + FN)真实缺陷中漏掉的比例与同一口径下 Recall 互补
良品误判率良品中被判为异常的比例属于件级指标，不等于 1 - Precision

TP、FP、FN 必须在指定统计层面定义：按图、按工件、按缺陷实例还是按像素。检测框需要明确匹配规则与 IoU 阈值；同一缺陷被重复报警是否合并，也会改变统计结果。不要把像素级指标直接当成工件合格判断能力。

教学例子：100 个真实缺陷找到 90 个，同时错误报出 10 个，则在这一缺陷实例口径下 Precision 和 Recall 都是 90%。若另外有大量良品，该结果仍不能直接给出良品误判率。示例只说明口径，不是实际测试成绩。

06

部署、联动与错例闭环

检测结果如何真正进入业务流程？

检测器输出只是中间结果，还需要映射回原图、合并同一工件的多帧结果、记录缺陷位置、形成报警并与现场处置衔接。报警应带时间、工件标识、图像、区域、类别、置信度和模型版本，让结果能够追溯。

业务阈值不一定只看模型置信度，还可能考虑缺陷尺寸、位置、连续出现次数或等级。连续帧去重需要兼顾漏报与重复报警；涉及触发、剔除或其他执行设备时，应把传感器位置、输送速度、通信和执行延迟一起纳入联调。

  1. 分别保留漏检、误报、定位偏差和类别混淆样本。
  2. 检查成像是否变化，再检查标注、数据分布、预处理和模型输出。
  3. 固定回归集合，验证新模型是否改善旧问题并引入新问题。
  4. 部署记录关联模型、阈值、环境和测试结果，支持回滚。

如果吞吐跟不上，应明确丢帧或降采样策略是否允许，不应无界排队，让结果在很久以后才出现。端到端延迟、稳定运行和故障恢复，与识别精度同样需要验收。

07

学习小结

我应该如何判断下一步优化成像还是算法？

这次整理让我认识到，表面检测是一条由质量规则、成像、数据、算法和现场联动共同构成的链路。先确认缺陷是否可见，再建立可解释的基线；有了清楚的错例和统计口径，才能判断下一步值得投入在哪里。

  • 看不清：优先检查视野、分辨率、光照、曝光和运动模糊。
  • 看得清但规则不稳：检查背景变化、缺陷定义、传统方法的适用条件。
  • 模型表现波动：检查数据覆盖、标注一致性、分布变化和预处理契约。
  • 离线好、现场差：检查传输、图像缩放、阈值、连续帧和实际业务口径。

后续练习可从固定成像条件下的一类缺陷开始，保留一组正常、异常和临界样本，记录每次规则调整的漏检与误报变化。先形成可复查的小闭环，再扩展类别和工况。
