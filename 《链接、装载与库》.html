贯穿全书的例子：一台迷你计算器

后面的实验都围绕同一组文件展开。main.c 调用另一个模块里的 add，我们一路观察声明、目标文件、未定义符号、静态链接、共享库、装载和运行库。

calc.h

#ifndef CALC_H
#define CALC_H
int add(int a, int b);
#endif

calc.c

#include "calc.h"
int add(int a, int b) {
    return a + b;
}

main.c

#include <stdio.h>
#include "calc.h"

int main(void) {
    printf("20 + 22 = %d\n", add(20, 22));
    return 0;
}

贯穿问题：main.c 里只有 add 的声明，真正的机器码在哪个阶段与它接上？后面每章都会从新角度回答。

字节序

多字节整数在内存中需要约定排列顺序。小端把最低有效字节放在低地址，大端相反。字节序影响二进制文件、网络协议和跨平台数据交换，但不改变数值本身。

目标常用命令你在看什么
编译到目标文件gcc -c a.c -o a.o先不链接
查看 ELF 头/段/符号readelf -h/-S/-s a.o文件结构与符号
反汇编objdump -d a.o机器指令与地址
查看动态依赖ldd app程序需要哪些共享库
查看符号nm a.o定义、未定义、局部/全局
追踪系统调用strace ./app用户程序如何请求内核

高频概念一口气区分

段（section）偏向链接器看文件内容如何分类；段/区段（segment）偏向装载器看哪些内容按同一权限映射。静态库在链接时抽取成员复制进程序；共享库在装载或运行时映射并解析。API是程序员调用的接口；系统调用是穿过用户态/内核态边界的机制；运行库往往在两者之间提供更友好的封装。
